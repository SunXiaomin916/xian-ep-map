# 西安电子警察分布地图（网页版）

> **数据来源：西安交警微信服务号——电子警察分布告知**

这是一个单文件网页应用（地图 + 点位查询 + 限行导航 + 尾号限行查询），
数据已内嵌，除百度地图 JS 外无需任何后端。

## 使用方法

### 方式一：本机 / 局域网访问（推荐，其他设备可直接打开）

1. 安装 [Node.js](https://nodejs.org/)（任意较新版本）。
2. 双击 `启动服务器.cmd`（Windows），或在终端里执行：
   ```
   node server.cjs
   ```
   也可指定端口：`node server.cjs 9090`（默认 8080）。
3. 终端会列出「局域网访问」地址，例如 `http://192.168.1.100:8080`。
4. 同一局域网内的手机、平板、电脑，用浏览器打开该地址即可访问。

### 方式二：部署到服务器 / 云主机

把整个文件夹上传到任意静态服务器（Nginx、宝塔、GitHub Pages、对象存储等），
以 `index.html` 作为默认首页即可，无需安装依赖。

## 重要：百度地图 AK 白名单

页面使用百度地图浏览器端密钥。若通过局域网 IP 或域名访问时地图无法显示
（提示 Referer 校验失败），请前往
[百度地图开放平台](https://lbsyun.baidu.com/) → 应用管理 → 设置 Referer 白名单，
加入你的访问地址，例如：

- `http://192.168.1.100:8080/*`
- `http://你的域名/*`
- 或设为 `*`（允许所有来源，安全性较低，仅建议内网临时使用）

## 功能

- 电子警察点位地图（2149 个点位，聚合 / 热力图）
- 按区域、违法类型、状态筛选 + 关键词搜索
- 限行导航：正常导航 / 避开限行监控，统计途经限行摄像头数量
- 尾号限行查询（按车牌尾号判断当天是否限行，仅供参考）
